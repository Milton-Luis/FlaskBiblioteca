# FlaskBiblioteca - projeto de Biblioteca Online

FlaskBiblioteca é um projeto de biblioteca online baseado no meu TCC, usando o framework Flask e suas extensões. O Objetivo do projeto é fornecer uma plataforma de fácil uso para o gerenciamento de livros e emmpréstimos.

## Funcionalidades

Cadastro de livros, Cadastro de usuários, Empréstimos e devolução, busca por livros, autenticação, e autorização, painel adminsitrativo.
